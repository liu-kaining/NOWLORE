# NOWLORE 文档罗盘

状态：`Baseline v1`  
负责人：ThetaMind / NOWLORE  
最后更新：2026-09-01

## 1. 一句话定义

NOWLORE 是一套“热点信号 → 证据聚合 → AI 判断 → Meme 文化方案 → 人工审批 → 链上发行 → 公开追踪”的透明工作流。

它不是自动炒币机器人，也不是收益承诺平台。它是一家长期存在的链上文化工作室，每一个代币是有明确实验周期、资料来源和风险披露的独立文化实验。

## 2. 产品原则

1. **证据先于叙事**：任何候选热点必须保留来源、时间与原始链接。
2. **判断可解释**：AI 输出必须包含理由、置信度、窗口期与反方证据。
3. **短期属性明示**：所有项目明确标注“短周期文化实验、无长期价值承诺”。
4. **发行公平透明**：团队不预留；如发生创建者首购或任何持仓，必须在发行前公开数量、地址和理由。
5. **收入公开**：创作者钱包、Creator Fee、领取交易与流向进入公开账本。
6. **不可逆动作有人把关**：真实主网发行需要明确审批；默认 dry-run。
7. **不制造虚假市场**：系统不做刷量、对敲、机器人拉盘、虚假社交证明或隐蔽砸盘。
8. **完整留痕**：采集、分析、编辑、审批、资产发布、模拟、发行、失败和配置变更都有审计事件。
9. **供应商可替换**：AI、数据源、对象存储、数据库、RPC 与链上发行适配器均通过接口隔离。
10. **先小后大**：先证明热点识别和透明发行闭环，再扩张自动化与信息源。

## 5. MVP 完成定义

只有同时满足以下条件，MVP 才算完成：

- 新仓库可通过一条命令安装并本地启动。
- 无任何密钥时可用 mock AI、JSON 存储和 dry-run 完成全流程。
- 至少支持 RSS、Polymarket、Hacker News、Hugging Face 和人工输入。
- 支持 OpenAI Responses、OpenAI-compatible Chat Completions、Anthropic Messages 三类远程 AI 调用。
- 可生成结构化评估和完整 Meme 发行包，并能人工编辑。
- 真实发行前必须通过审批、资产可访问性检查、RPC 模拟和主网开关。
- Pump 集成使用官方 SDK；网络/SDK 变化时快速失败而不是猜测交易。
- 公开页面展示项目生命周期、依据、创建者钱包、交易和费用快照。
- 所有管理动作写入只追加审计日志。
- 单元、集成、API 和前端构建检查通过。
- Docker、Cloud Run、Cloudflare、环境变量和恢复流程有文档。

## 6. 不做的事情

- 不自动购买或出售已发行代币。
- 不提供收益率、价格目标、稳赚、保本等承诺。
- 不提供刷量、抢跑、捆绑钱包、女巫账户或规避平台规则的能力。
- 不绕过 Pump 或 Solana 的协议校验。
- 不抓取需要登录或禁止自动化访问的公众号页面；公众号内容通过合法 RSS、Webhook 或人工导入。
- 不在公开 API 返回密钥、内部提示词、未发布概念或私人审批信息。

## 7. 成功指标

产品指标：信号入库延迟、去重率、从发现到可审批方案的耗时、人工采纳率、误报率、风险拦截率。  
工程指标：任务成功率、数据源错误率、AI 结构化输出成功率、模拟成功率、审计覆盖率。  
透明度指标：公开来源覆盖率、钱包披露完整度、Creator Fee 对账差异、发行记录完整度。

交易量与币价不是系统成功指标，避免产品激励滑向操纵市场。
